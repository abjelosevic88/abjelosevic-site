# abjelosevic-site

Personal site for Aleksandar Bjelošević, built with [Astro](https://astro.build). Static output, no client-side framework, one dependency.

Live on the tailnet at **https://cv.lab.bjelke.org**.

## Develop

```bash
pnpm install
pnpm dev        # http://localhost:4321/
pnpm build      # outputs to dist/
pnpm preview
```

## Edit content

Everything shown on the page lives in `src/data/site.ts`: profile, stats, experience, skills, the Pocket Homelab section, education. Components in `src/components/` only render that data.

The portrait is `src/assets/avatar.jpg`.

## Theme

Terminal look: monospace, phosphor green on near-black. Dark is the default; the header button switches to a light variant and the choice is remembered in `localStorage`. Both palettes are the variable blocks at the top of `src/styles/global.css`.

## Deploy

### Homelab (cv.lab.bjelke.org)

Caddy on `personal-nixos` serves `/var/www/cv` — see `~/nix/nixos/personal-nixos/homelab/cv-site.nix`. After any change:

```bash
pnpm deploy     # astro build && rsync dist/ -> /var/www/cv/
```

The `*.lab.bjelke.org` wildcard already points at the box's Tailscale address, so the name only works from tailnet devices.

### Public site (abjelosevic.com, Cloudflare Workers)

Cloudflare builds and deploys from this repository on every push to `main`, as a Worker serving static assets (`wrangler.jsonc`):

| Setting | Value |
|---|---|
| Build command | `pnpm build` |
| Deploy command | `npx wrangler deploy` |
| Environment variable | `NODE_VERSION=22` |

`public/_headers` sets caching and security headers; `404.html` is served for unknown paths. The `www.` → apex redirect is a Cloudflare Redirect Rule on the zone (Workers assets do not allow host-based rules in `_redirects`).

## SEO and assets

- Canonical URL, Open Graph, Twitter card and JSON-LD (`WebSite` + `Person`) come from `src/layouts/Base.astro`; the description lives in `src/data/site.ts`.
- `sitemap-index.xml` is generated by `@astrojs/sitemap`; `public/robots.txt` points at it and disallows `/cv/`.
- `pnpm assets` regenerates `public/og.png` (1200×630 share image) and the PNG icons from `src/assets/avatar.jpg` and `public/favicon.svg`. Run it after changing the portrait, name or title.
- The CV PDF is `public/cv/Aleksandar-Bjelosevic-CV.pdf`, linked from the hero and contact sections and marked `noindex`.
